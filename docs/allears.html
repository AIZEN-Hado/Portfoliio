All-Ears

Spotify-Inspired Music Streaming App — First Android Application

React Native Expo 54 TypeScript Firebase Android In Progress

Overview

All-Ears is a modern music streaming application where users can listen to songs, discover artists, create playlists, and enjoy a complete role-based music experience.

This project is special — it is the very first Android app I built. It taught me real-world mobile app development: Firebase integration, authentication flows, audio playback, and structuring a larger app with modern tools.

StatusIn progress — my milestone project for Android-focused mobile development.

Features

  • 🔐 Google Sign-In authentication
  • 👤 Role-based access for Listener, Artist, and Admin
  • 🎶 Music playback with queue, shuffle, repeat, and recently played tracking
  • 🔍 Search songs, artists, and genres
  • ❤️ Like songs and build a personal music library
  • 📃 Create and manage playlists
  • 🎤 Artist upload flow for songs and cover art
  • ✅ Admin approval and rejection system for songs
  • 👥 Admin user management with role updates and bans
  • 📊 Analytics dashboard for users, plays, top songs, and genre insights

User Roles

🎧 Listener

  • Discover trending songs and new releases
  • Search songs, artists, and genres
  • Like songs and organize playlists
  • View recently played music
  • Explore artist profiles

🎤 Artist

  • Upload original songs
  • Add cover art and genre details
  • Submit tracks for approval
  • Share music with listeners on the platform

🛠️ Admin

  • Review and moderate uploaded songs
  • Approve or reject submissions
  • Manage users and update roles
  • Ban or unban accounts
  • Monitor platform analytics and activity

Getting Started

1

Clone the repository

git clone https://github.com/AIZEN-Hado/ALL-EARS.git
cd ALL-EARS
2

Install dependencies

npm install
3

Add environment variables

Create a local environment file and add:

EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your_google_web_client_id
4

Set up Firebase

Make sure your Firebase project has:

  • Firebase Authentication enabled
  • Google Sign-In enabled
  • Firestore Database enabled
  • Firebase Storage enabled
  • Android app configuration added correctly
5

Start the app

npm run android   # run on Android
npm start         # or start the development server
