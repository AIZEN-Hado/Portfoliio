InterviewIQ

AI-Powered Interview Platform

React Node.js · Express MongoDB JWT Auth LLM Integration Live on Render

Overview

InterviewIQ is a full-stack AI-driven interview platform designed to simulate real-world hiring processes by automating interview creation, candidate evaluation, and response analysis.

Built with a modern tech stack, the platform enables dynamic interview experiences, real-time feedback, and intelligent candidate assessment using AI.

Live DemoThe platform is deployed and usable right now: interviewiq-vm8j.onrender.com

Key Features

  • AI-Powered Interview Engine — dynamically generates interview questions based on resume data and job requirements.
  • Resume Screening & Analysis — upload resumes and automatically extract key insights for candidate shortlisting.
  • Real-Time Response Evaluation — analyze candidate answers with structured feedback and performance insights.
  • Smart Interview Workflow — end-to-end pipeline from interview creation → candidate interaction → evaluation.
  • Analytics Dashboard — visualize candidate performance with charts and actionable metrics.
  • Scalable Architecture — designed to handle real-time interactions and asynchronous workflows efficiently.

Installation & Setup

Prerequisites

  • Node.js (v18 or above recommended)
  • npm or yarn
  • MongoDB (local or MongoDB Atlas)
  • Git
1

Clone the repository

git clone https://github.com/AIZEN-Hado/3.interviewIQ.git
cd 3.interviewIQ
2

Install backend dependencies

cd server
npm install
3

Install frontend dependencies

cd ../client
npm install

Environment Variables

Server

Create a .env file inside the server folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
OPENAI_API_KEY=your_api_key   # if used

Client

Create a .env file inside the client folder:

REACT_APP_API_URL=http://localhost:5000

Running the Application

1

Start the backend server

cd server
npm start

Backend runs on http://localhost:5000

2

Start the frontend

cd client
npm start

Frontend runs on http://localhost:3000

Optional improvements

Auto-restart the backend with Nodemon:

npm install -g nodemon
nodemon server.js

Run frontend & backend together:

npm install -g concurrently

Verify Setup

  • Open http://localhost:3000
  • Ensure the frontend loads correctly
  • Check the backend connection (no console errors)
  • Test basic features (login / interview flow)

Common Issues & Fixes

Port already in use

npx kill-port 5000

MongoDB connection error

  • Verify MONGO_URI
  • Ensure the MongoDB service is running

node_modules issues

rm -rf node_modules package-lock.json
npm install

Environment variables not loading

  • Ensure .env is in the correct directory
  • Restart the server after changes
