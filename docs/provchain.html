ProvChain

AI Code Provenance & Drift Intelligence Platform

ML Risk Scoring 200+ Live CVEs Drift Detection CVSS Embeddings CI/CD Security

Overview

ProvChain is an AI-powered code provenance engine that audits AI-generated code against 200+ live CVE records, producing explainable risk classifications and remediation recommendations for scalable CI/CD security auditing.

It combines drift detection, CVSS severity, and semantic similarity into a multi-signal ML risk-scoring framework — reducing manual security review effort by 80%.

In one lineAI code enters the pipeline → ProvChain traces where it came from, how far it drifted, and what it might carry — before it ships.

The Problem

AI assistants now write a large share of production code, and that code enters codebases largely unaudited. Generated snippets can reproduce vulnerable patterns from training data, drift from vetted implementations, or embed dependencies with known CVEs. Manual security review cannot keep pace with the volume — teams need automated provenance and risk intelligence at the point where code merges.

Capabilities

Provenance Auditing

Where did this code come from?

Audits AI-generated code against 200+ continuously updated CVE records, flagging fragments that match or resemble known-vulnerable patterns.

Drift Detection

How far has it moved from the baseline?

Measures how generated code diverges from vetted reference implementations — drift is a leading signal of silent behavioral or security change.

Explainable Risk Classification

Why is this risky?

Every classification carries its contributing signals — drift magnitude, CVSS severity, similarity score — so reviewers see the reasoning, not just a verdict.

Automated Remediation

What should be done about it?

An embeddings-based retrieval pipeline surfaces vulnerability explanations and concrete remediation recommendations alongside each finding.

Multi-Signal Risk Scoring

Risk is never a single number from a black box. ProvChain fuses three independent signals into one explainable score:

SignalWhat it measuresWhy it matters
Drift detectionDivergence from vetted baseline implementationsSilent drift precedes silent vulnerabilities
CVSS severityIndustry-standard severity of any matched CVEAnchors the score to recognized threat impact
Semantic similarityEmbedding-space closeness to known-vulnerable codeCatches rewrites and paraphrases that string matching misses
risk = f( drift, cvss, semantic_similarity )
     → classification + contributing-signal breakdown
     → explanation + remediation recommendation

Embeddings Retrieval Pipeline

  1. Ingest — AI-generated code enters from the CI/CD pipeline or review queue.
  2. Embed — code fragments are embedded into a vector space alongside indexed CVE records and vulnerable-pattern corpora.
  3. Retrieve — nearest known vulnerabilities and reference implementations are pulled for comparison.
  4. Score — the multi-signal framework classifies risk with full signal attribution.
  5. Explain — matched CVEs are summarized with automated vulnerability explanations and remediation steps.

CI/CD Integration

ProvChain is designed to run where code review actually happens — as an automated gate in the delivery pipeline. Findings are produced per commit or per merge request, so risky AI-generated code is caught before it reaches production, at a scale no manual review process can match.
