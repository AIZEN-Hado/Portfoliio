Mission 02 · Creator & Architect — 2025

SemiGit

AI-Powered Semantic Commit Generation — VS Code Extension

Problem
Git history is noisy — "wip", "fix", "final2" — because commits happen when a developer feels done, not when a real unit of work is complete. Existing tools format messages; none decide when a commit should happen or what it represents.
Solution
A local-first VS Code extension that watches your session, diffs code structurally via the TypeScript Compiler API, scores feature-level milestones, and writes the Conventional Commit — fully offline by default, with five optional AI providers (OpenAI, Claude, Gemini, DeepSeek, Ollama) behind one interface.
Results
One universal .vsix (SQLite in WebAssembly, no native modules), 90+ tests on a 3-OS CI matrix, and output quality measured against real git history via a backtest harness — not asserted.

Mission 06 · Backend Engineer — 2026

Offline UPI Mesh

Secure Offline Payment Simulation over Mesh Networking

Problem
Digital payments fail entirely without internet connectivity — a critical gap in low-connectivity regions.
Solution
A Spring Boot backend simulating offline UPI payments: transactions are encrypted (RSA + AES-GCM), wrapped into TTL-bound mesh packets, gossiped device-to-device until a bridge device with internet relays them to the server for settlement.
Results
End-to-end cryptographically secure payment flow that survives total sender-side network loss, with gossip-protocol packet propagation.
  • Java
  • Spring Boot
  • RSA + AES-GCM
  • Mesh Networking
  • Gossip Protocol
